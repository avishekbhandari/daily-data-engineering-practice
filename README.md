# Daily Data Engineering Practice

This repository contains my ongoing data engineering practice work across Python, SQL, PySpark, Azure fundamentals, and small sample datasets.

The goal of this repo is to document hands-on practice with common data engineering concepts such as data cleaning, joins, aggregations, window functions, ETL logic, PySpark DataFrames, SQL problem solving, and cloud fundamentals.

---

## What This Repository Covers

- Python and Pandas practice
- PySpark DataFrame operations
- PySpark joins, aggregations, and data cleaning
- SQL window functions
- SQL joins, deduplication, ranking, and running totals
- Azure data engineering fundamentals
- Small sample datasets for local practice

## Main Practice Areas

### PySpark

The `PySpark/` folder includes practice notebooks for:

- reading CSV files
- cleaning null values
- joining datasets
- groupBy and aggregation
- ETL logic
- PySpark case studies
- DataFrame transformations

### SQL

The `sql/` folder includes practice notebooks for:

- latest order per customer
- deduplication using `ROW_NUMBER`
- previous-order comparison using `LAG`
- next-order comparison using `LEAD`
- `RANK` vs `DENSE_RANK`
- running totals
- product and order analysis problems

### Python

The `python/` folder includes Python and Pandas practice notebooks focused on basic data manipulation and DataFrame work.

### Azure

The `azure/` folder includes Azure fundamentals notes for building cloud data engineering knowledge.

### Data

The `data/` folder contains small CSV files used for practice examples, including customer and order datasets.
